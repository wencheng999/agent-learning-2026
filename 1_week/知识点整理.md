## 为什么一个逗号就会变成 tuple？

Python 中：

```
x = "Agent"
```

是字符串。

但是：

```
x = "Agent",
```

实际上是：

```
x = ("Agent",)
```

也就是只有一个元素的元组。

```
x = "Agent"
y = "Agent",

print(type(x))
print(type(y))
```

输出：

```
<class 'str'>
<class 'tuple'>
```

> **元组本质上不是由括号决定的，而是由逗号决定的。**

比如：

```
x = 1, 2, 3
```

也是 tuple：

```
(1, 2, 3)
```





## def save_memory(content: str) -> None:

```
def save_memory(content: str) -> None:
```

表示：

> 这个函数不打算返回有效结果。

例如：

```
def hello() -> None:
    print("Hello")
```

调用：

```
result = hello()
```

虽然 Python 底层实际上还是会得到：

```
None
```

但是写：

```
-> None
```

主要是在告诉程序员：

> 这个函数的作用是执行操作，不是计算并返回结果。
