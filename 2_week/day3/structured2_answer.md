练习5：

Prompt = 引导 ，用于LLM大体需要输出什么格式内容

Schema = 结构定义  用于严格要求LLM的输出内容格式是什么

Pydantic = 验收  用户验证LLM的输出内容格式是否符合Pydantic要求的格式。

Retry / Repair = 恢复 如果LLM输出的内容格式不正确，则进行retry重试，或者加入错误原因进行repair修补。

```
Prompt
→ 告诉模型“你要做什么”

Schema
→ 定义“合法结果长什么样”

Pydantic
→ 检查“实际结果到底合不合法”

Retry / Repair
→ 不合法时“如何恢复”
```
